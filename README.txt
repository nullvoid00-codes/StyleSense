# STYLE SENSE – Fashion Recommendation & ML Prediction App

## Pages
1. Home – project introduction and H&M dataset information.
2. Fashion Recommendations – customer profile, KNN/hybrid recommendations, with popularity fallback if KNN cannot load.
3. ML Predictions – next purchase category and low-sales risk.
4. Model Performance – displays the saved Colab evaluation metrics.

## Project files
- `app.py`: Streamlit user interface.
- `recommendation.py`: recommendation functions and artifact loading.
- `artifacts/`: models, sparse interaction matrix, product/customer mappings, catalog and evaluation CSVs.

## Important model compatibility
The supplied prediction model pickle files were saved with scikit-learn 1.6.1. Use that version to load them reliably. The requirements file pins `scikit-learn==1.6.1`. If your existing virtual environment has a different version, create a fresh virtual environment rather than randomly upgrading/downgrading packages in the existing one.

## Run in PyCharm / terminal

1. Extract this ZIP.
2. Open the extracted `StyleSense_Final` folder in PyCharm.
3. Open the PyCharm terminal.
4. Create and activate a virtual environment (recommended).
5. Install dependencies:

   `python -m pip install -r requirements.txt`

6. Start the app:

   `streamlit run app.py`

## Recommendation page notes
The supplied artifacts include:
- `interaction_matrix.npz`
- `customer_ids.pkl`
- `product_ids.pkl`
- `product_popularity.pkl`
- `product_details.pkl`
- `similarity_model.pkl`

The recommendation code validates that matrix dimensions match the customer and product ID lists. If the KNN artifact cannot be loaded, the page still provides popularity-based recommendations where possible.

## Prediction page notes
The prediction page loads:
- `next_purchase_model.pkl`
- `sales_risk_model.pkl`

The form fields match the feature names recorded in `prediction_feature_info.pkl`:
- Next purchase: `tops_count`, `bottoms_count`, `dresses_count`, `jackets_count`, `total_purchases_90d`, `average_price_90d`, `days_since_last_purchase`, `favourite_colour`.
- Low-sales: `sales_last_30_days`, `sales_last_60_days`, `sales_last_90_days`, `average_price_90_days`, `product_group_name`, `product_type_name`, `colour_group_name`.

Predictions depend on input quality and should be interpreted as model estimates, not guarantees.

## Metrics
The Model Performance page reads the saved comparison CSVs generated by the Colab notebook. It does not retrain models.
